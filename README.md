# STV-HugoWriter

> [!NOTE]
> このリポジトリに含まれている成果物は、すべてClaude Code（Fable5）によって生成したものです。
> Small Travelersは、この成果物を使用したことによって発生した不利益について一切の責任を負いかねます。

だれでも簡単に使える、Windows 用の Hugo ライター & ジェネレーターです。
複数人が所属する団体・企業での利用を想定しており、各メンバーの PC にインストールして使います。

- インストール手順: [docs/install-guide.md](docs/install-guide.md)
- 管理者向けガイド: [docs/admin-guide.md](docs/admin-guide.md)

- **執筆者**: 記事の作成・編集・削除、見たまま編集 (WYSIWYG) / Markdown、サイトのライブプレビュー
- **管理者**: サイト側の設定 (セクション構成・入力項目など) を `wpgen.site.json` で一元管理
- 個人の執筆環境 (文字サイズ・自動保存・署名など) は各ユーザーが自由に変更できます

## 使い方 (執筆者向け)

1. インストーラ (`STV-HugoWriter Setup *.exe`) でインストールします ([インストールガイド](docs/install-guide.md))。
2. 初回起動時に、管理者から共有された **Hugo サイトのフォルダ** を選択します。
   (試すだけなら、このリポジトリの `sample-site` フォルダを選択してください)
3. 「+ 新しい記事」でタイトルを入力すると下書きが作られます。
4. 上部の「サイトをプレビュー」を押すと、右側に実際のサイトの見た目が表示されます。
   記事を保存すると自動的にプレビューへ反映されます。
5. 公開してよい状態になったら「下書き」のチェックを外して保存します。

- 保存は `Ctrl+S` またはボタン。自動保存 (既定 5 秒) も有効です。
- 「設定」→「執筆環境」から文字サイズ・エディタ初期モード・署名などを変更できます。
  アプリのバージョンは設定画面の左下に表示されます。

### Git で共有する (v0.2 から)

サイトを Git リポジトリで共有している場合は、上部に同期ボタンが表示されます。

- **最初の一回**: ようこそ画面で管理者から受け取ったリポジトリ URL を入力し「リポジトリから取得」
- **書き始める前**: 「最新を取得」を押して他のメンバーの変更を取り込む
- **書き終わったら**: 「変更を送信」を押す (自動で保存 → 取得 → 送信まで行われます)
- 他のメンバーと同じ箇所を編集して競合した場合は送信を中止し、あなたの変更はローカルに残ります。
  表示される案内に従って管理者に相談してください。

利用には各 PC に [Git for Windows](https://gitforwindows.org/) が必要です
(プライベートリポジトリでは初回にブラウザで GitHub へのサインインを求められます)。

## 管理者向け

サイトに関する設定は、**Hugo サイトフォルダ直下の `wpgen.site.json`** で管理します。
アプリの画面からは閲覧のみ可能で、執筆者は変更できません。
詳細は [docs/admin-guide.md](docs/admin-guide.md) を参照してください。

## 開発者向け

必要環境: Node.js 20+ / Hugo (extended)

```
npm install
npm run dev        # Vite + Electron を起動 (開発モード)
npm run dist       # Windows インストーラをビルド (release/ に出力)
```

- `electron/` … メインプロセス (ファイル操作・Hugo サーバ管理・Git/FTP・設定管理)
- `src/` … レンダラ (React + Toast UI Editor)
- `resources/bin/hugo.exe` … パッケージに同梱する Hugo 本体 (未配置なら PATH 上の hugo を使用)
- `sample-site/` … 動作確認用のサンプル Hugo サイト (テーマ `wpgen-basic` 同梱)
- アプリのアイコンを変える場合は `build/icon.ico` (256×256 を含むマルチサイズ .ico) を置いて
  `npm run dist` を実行します (`build/icon.png` 512×512 以上でも可、自動変換されます)

### サイトの公開 (v0.3 から)

管理者が公開先 (FTP/FTPS) を設定しているサイトでは、上部に緑の「**サイトを公開**」ボタンが表示されます。
押すと下書きを除いた本番ビルドが作られ、サーバへアップロードされます。
FTP パスワードは初回に入力し、希望すれば自分の PC に暗号化保存されます。
