# STV-HugoWriter インストールガイド

団体のメンバーの PC に STV-HugoWriter を導入する手順です。

## 動作環境

- Windows 10 / 11 (64bit)
- ディスク空き容量: 500 MB 程度
- インターネット接続 (Git 同期・サイト公開時に必要)

## 前提ソフトウェア

| ソフトウェア | 必要になる場面 | 入手先 |
| --- | --- | --- |
| **Git for Windows** | Git 同期機能 (「最新を取得」「変更を送信」「リポジトリから取得」) を使う場合は**必須** | <https://gitforwindows.org/> |

- インストールは既定の設定のままで問題ありません (Git Credential Manager が含まれます)。
- Hugo (サイト生成エンジン) は **STV-HugoWriter に同梱**されているため、個別のインストールは不要です。
- 執筆・プレビュー・FTP 公開だけを使う場合、Git for Windows は無くても動作します
  (その場合は同期ボタンが表示されません)。

## インストール手順

1. **Git for Windows をインストール**する (上記。既にあればスキップ)。
2. **`STV-HugoWriter Setup <バージョン>.exe` を実行**する。
   - インストーラは管理者から受け取るか、リポジトリの Release からダウンロードします。
   - 「Windows によって PC が保護されました」と表示された場合は
     「詳細情報」→「実行」を選択してください (コード署名を行っていないための表示です)。
   - インストール先は既定のままで構いません (ユーザーごとのインストールです)。
3. インストール後、スタートメニューから **STV-HugoWriter** を起動します。

## 初回セットアップ (執筆者)

1. 起動すると「ようこそ」画面が表示されます。
2. 管理者から受け取った **Git リポジトリの URL** を入力して「リポジトリから取得」を押すか、
   既にサイト一式のフォルダが PC にある場合は「サイトのフォルダを選択…」で開きます。
   - プライベートリポジトリの場合、初回にブラウザで GitHub へのサインインを求められます。
     自分の GitHub アカウントでサインインしてください (リポジトリへのアクセス権が必要です)。
3. 「設定」→「執筆環境」で **署名 (名前)** と **メールアドレス** を入力します。
   Git の更新履歴に記録される名前になります。

以降の使い方は [README](../README.md) の「使い方 (執筆者向け)」を参照してください。

## 更新 (バージョンアップ)

新しい `STV-HugoWriter Setup <バージョン>.exe` を実行するだけで上書き更新されます。
設定・記事はそのまま引き継がれます。

## アンインストール

Windows の「設定」→「アプリ」から STV-HugoWriter を削除してください。
個人設定を完全に消したい場合は、あわせて `%APPDATA%\STV-HugoWriter` フォルダを削除します。
サイトの原稿 (Git リポジトリのフォルダ) は削除されません。
